# Plan de révision GitHub Foundations

Environ 1 h par jour, 5 jours par semaine, pendant 3 semaines.

## Semaine 1 : Git et collaboration

- [ ] Jour 1 : branches (`git switch -c`, `git merge`, `git log --oneline --graph`)
- [ ] Jour 2 : pull requests (`gh pr create`, review, merge / squash / rebase)
- [ ] Jour 3 : provoquer un conflit de merge et le résoudre
- [ ] Jour 4 : issues, labels, milestones, `Closes #1`
- [ ] Jour 5 : fork + PR sur un autre repo ; README, LICENSE, CONTRIBUTING, `.gitignore`

## Semaine 2 : fonctionnalités GitHub

- [ ] Jour 1 : un workflow GitHub Actions qui se lance à chaque `push`
- [ ] Jour 2 : Projects (tableau, kanban), Discussions, Wiki, Gists
- [ ] Jour 3 : Codespaces, Copilot, éditeur github.dev (touche `.`)
- [ ] Jour 4 : sécurité (2FA, Dependabot, secret scanning, protection de branche)
- [ ] Jour 5 : organisations, équipes, rôles, plans GitHub, visibilité des repos

## Semaine 3 : révisions et examen

- [ ] Jours 1-2 : tests d'entraînement, noter les questions ratées
- [ ] Jours 3-4 : réviser les points faibles
- [ ] Jour 5 : plus de 80 % aux tests, réserver l'examen
